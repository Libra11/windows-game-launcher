## 游戏操作

- 新增游戏专用右键菜单与卡片「更多操作」，集中提供启动／安装、详情、收藏、收藏夹、标签和管理入口。
- 支持多选游戏批量整理；收藏夹子菜单可搜索并连续勾选归属。
- 修复键盘无法进入收藏夹搜索框的问题，展开时先聚焦搜索框，上下方向键可在搜索与菜单项间切换。
- Steam 未安装游戏提供「安装游戏」，安装完成后恢复启动入口；Epic 新增独立安装入口。

## 收藏夹拖拽

- 支持拖拽单款或已选多款游戏加入收藏夹，悬停展开侧栏收藏夹。
- 拖拽预览使用游戏封面，并增加开始动画、多选数量与落点提示。
- 修复按 Esc 取消拖拽后继续按住鼠标、延迟松开导致的误点击。

## Steam 时长

- 统一自有库与家庭库的本人时长同步，启动、定时刷新、游戏结束及手动更新时一并同步。
