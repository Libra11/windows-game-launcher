## 在线搜索

- 新增 Gamer520 在线搜索入口，使用游迹自己的界面查看游戏名称、封面、版本说明、分类与发布日期。
- 支持中文／英文关键词、当前页 PC 游戏筛选、全部类型和翻页。搜索失败保留上次结果，提供重试及原站入口。

## 在线详情与网盘资源

- 点击搜索结果即可在游迹内查看游戏介绍、配置要求、图片与下载资源。
- 展示已识别的网盘分享链接、提取码、原站文件密码和解压密码，支持复制与打开网盘。
- 需要访问密码的资源页使用主站公开密码按原站正常流程读取；不读取浏览器登录凭据，不登录用户网盘账号。
- 根据原始分享链接在本机生成二维码，不向第三方二维码服务发送链接；读取不到的下载方式保留原站入口。

## 界面与体验优化

- 搜索结果采用完整封面卡片，区分名称、版本、资源类型和日期，沿用现有主题与字体。
- 在线详情采用紧凑的封面与资料布局，下载区集中展示密码，通过网盘选择切换对应链接和二维码。
- 支持键盘切换网盘；刷新保留仍可用的网盘选择和焦点，返回搜索结果恢复原位置。
- 修复《尘埃异变 GRIME》等页面的纯文本网盘地址未被识别的问题，并读取相邻段落的提取码。
- 修复缓存详情页重新进入后二维码偶发显示空白的问题，使用直接呈现的本地矢量二维码保持清晰显示。
