## 游戏存档自动备份与目录识别

- 新增退出游戏后自动备份、文件稳定检测和内容去重；可选择自动上传云端，断网或重启后继续排队任务，已有档案默认关闭自动选项。
- 自动识别存档候选目录，显示匹配依据、文件数与大小；由你确认绑定，找不到时仍可手动选择。
- 恢复云端存档前展示版本差异并要求确认，保留安全备份；预览后本地内容变化时拒绝覆盖。
- 新增版本保留策略与手动保留，保护当前版本、分叉和未完成上传；清理归档后仍保留版本关系。
- 整理存档绑定界面，统一下拉菜单、复选框和操作分区。
- 修复 Xbox 待命监听阻塞存档备份，以及没有快照时误报云端备份成功的问题。
- 云端自动化功能需要配套新版服务端及数据库迁移；升级客户端保留原有游戏库、目录绑定和快照。

- 修复部分 Windows 登录凭据导致的启动失败、设置页输入卡顿和云资料导入重复扫描引起的预览失效，导入预览按游戏及数据类别汇总。
