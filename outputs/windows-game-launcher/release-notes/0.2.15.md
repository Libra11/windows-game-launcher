## 游迹云账号与手动存档

- 设置新增「游迹云账号」：连接自行部署的 HTTPS 服务，受邀邮箱验证码登录，一个本地资料库绑定一个云账号；首次导入需预览并确认，程序路径、代理和平台凭据不上传。
- 游戏详情新增手动存档档案，每个档案绑定一个专用目录；备份先保存本地快照，云上传失败仍可保留本地副本，恢复替换整个目录并先保存安全快照。
- 存档上传由独立后台 worker 校验后发布，文件上传完成不等于云端可恢复；详情页可查询状态并续传后续快照。
- 云端分叉需要显式选择分支，不按上传时间自动覆盖；游戏整理按资源版本处理离线冲突，待同步修改保留在本机。
- 云端存储使用 OSS 原生私有桶接口，对象统一位于独立前缀，签名地址由服务端签发；服务端与服务端部署说明随源码提供。
- 本次发布不包含自动部署或迁移用户数据；使用云端功能需要自行部署服务端并在设置中填写服务地址。
