## 应用内更新

- 设置新增「关于与更新」，支持查看中文说明、检查正式版、下载并安装新版本。
- 下载支持进度、取消及本地缓存复用，安装前验证签名与版本。
- 游戏或成就捕获运行时可下载，退出后再安装；安装前保存计时记录，完成后重新打开游迹。

## 游戏库与数据

- 新增跨平台标签和手动收藏夹，支持单款与批量整理。
- 收藏夹可在侧栏展开、折叠，管理界面支持搜索、重命名及调整顺序。
- 新增数据备份、完整恢复和游戏路径重定位；标签、收藏夹及外观设置随备份保存。

## 使用说明

- 应用内安装适用于 Windows x64 NSIS 正式安装版。
- 旧版本需要先手动安装本版，之后才能使用应用内更新。
