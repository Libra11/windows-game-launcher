# Xbox 公开成就资料与本地解锁

无需注册 Azure 应用，无需登录微软或 Xbox。资料来自 Exophase 公共 Xbox 成就页面；来源会显示在详情诊断中。

## 添加游戏

选择启动文件 → 检测 MicrosoftGame.config 的 Title ID 和 Store ID → 确认成就平台 → 关联对应 Xbox 公开资料页面 → 保存。Steam 搜索可以独立补全封面和简介，不会把 Steam 成就混入 Xbox。

Steam 识别检查启动目录及 Unity 的 `<启动文件名>_Data/Plugins`、`x86_64`、`x86` 目录，读取 `steam_appid.txt`、`steam_settings/steam_appid.txt`、`steam_emu.ini` 的 AppID，并检查 Steam 接口 DLL。DLL 只能提示平台，不能确认游戏编号或自动解锁能力。配置编号与所选游戏不一致时，必须明确勾选确认；启动器保存资料关联和核对原因，不修改游戏文件。

《黯井微光》已关联公开页面，附带 2026-10-01 核对的 41 项离线定义。其他游戏需要填写对应 Exophase 页面；没有可靠平台身份时拒绝合并。页面中 Microsoft Store ID 必须与本地一致，每项按真实 data-award-id 匹配，不能按站内编号或列表顺序匹配。

## 刷新与离线

启动自动载入已有 Xbox 游戏资料；详情的更新资料、设置的更新公开成就资料均可刷新。网络失败、站点验证或资料不完整时保留完整缓存，不将已有解锁归零。《黯井微光》优先显示简体中文，文本参考已逐项核对的 Steam 简体中文公开资料：https://www.exophase.com/game/well-dweller-steam/achievements/zh-CN/ 。显示文本由 Xbox 编号和原始条件共同校验；条件变化时保留原文，编号、图标和本地解锁来源不变。其他游戏按资料源语言显示。不会导入网页玩家解锁记录。

## 自动解锁边界

目前仅验证指定版本 Well Dweller 的 GDK 模块，捕获组件核对 SHA256。其他 Xbox 游戏可以取得定义，但不能保证自动捕获。

真实本地事件使用 xbox:<Title ID>:<achievement ID> 匹配。进度达到 100% 且接口成功回调后保存本地解锁。补全名称不会补发历史通知，已有本地解锁和来源保持不变，不上传到 Xbox。

## 长时间监听与异常

捕获持续到游戏退出、禁用捕获或启动器退出，不按固定一小时间隔解除和重新附加。退出时先暂停线程组，恢复本组件拥有的调试寄存器，恢复线程运行后解除附加；不会覆盖不属于本组件的断点。监听失败首次发送状态提示，同一错误不重复提醒，恢复后更新界面状态。
