# Xbox 本地事件捕获

首个验证对象为 Xbox PC《黯井微光》，Title ID `64439FE5`。
此组件使用 Windows 调试 API 和硬件执行断点，观察实际成就请求与完成回调，不修改游戏指令或存档。
仅接受固定 SHA256 的 `GDKExtension.dll`；其他版本拒绝附加，不猜测函数地址。

## 构建

在 Windows PowerShell 中执行 `./build.ps1`。输出为 `../resources/XboxLocalProbe.exe`，由 Tauri 作为资源打包。
代码通过 Windows 自带的 .NET Framework 编译器构建，不需要下载第三方二进制。
交叉构建 Tauri 前，应先在 Windows 构建此组件并复制到资源目录。

## 事件约定

- 日志位于启动器数据目录的 `xbox-local/64439fe5/<game-id>`。
- 只记录匹配本地可执行文件路径的进程；等待游戏启动，并在重启后重新附加。
- 只保存具有请求证据、进度 100%、完成回调 HRESULT 为 0 的事件。
- 成就定义键使用 `xbox:64439fe5`；成就 ID 使用 `xbox:64439fe5:<id>`，不与 Steam ID 混用。
- 首次读取历史事件不通知。每次附加后的前 60 秒静默保存事件，避免读档补报造成通知轰炸；此时真实新事件也会保存，但不弹窗。
- 此模块没有完整 Xbox 成就定义，未知名称显示“Xbox 成就 #ID”，不计算完整完成率。
- 这些记录表示当前运行环境的成功回调，不表示 Xbox 官方账号已解锁。
- 启动器退出、游戏移除、游戏退出时，恢复调试寄存器并解除附加；不强行结束游戏。

## 已验证位置

相对模块基址：`0x1AB38` 请求参数、`0x1ACD5` 用户缺失、`0x1AD82` 完成回调、`0x1ABB1` 上下文创建失败。
这些地址仅对源码中指定的模块哈希有效。
