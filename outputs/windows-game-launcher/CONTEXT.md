# 游迹的资料库领域

游迹管理个人的游戏与影视收藏。以下术语区分作品、文件及个人记录，避免将资料来源和本地资源混为一体。

## 影视

**影视条目**：可独立浏览、评分和标记观看状态的作品对象，包括电影、剧、季、集以及尚未识别的基础条目。条目不以取得联网资料或拥有文件为前提。

**本地资源**：媒体目录中实际存在的视频文件或可播放的影视目录。同一影视条目可以对应多个资源版本。

**媒体来源**：用户明确添加的媒体目录及其扫描范围。来源暂时不可访问与其中某个文件已经删除是不同情况。

**外部编号**：豆瓣、TMDB 等资料源对对象的标识，由来源、对象类型和编号共同确定，不替代条目的内部身份。

**资料对应**：确认多个资料来源描述的是同一部作品或同一季、集的关系。

**资源关联**：确认本地资源属于哪一个影视条目或具体集的关系。它与资料对应分别成立。

**观看状态**：个人是否已看过某个条目的标记。已看条目仍可以被重看并拥有未结束的播放进度。

**播放进度**：具体资源版本的当前位置。不同剪辑或文件版本不能直接套用同一个时间位置。

**豆瓣观影记录**：豆瓣来源的已看标记、个人星级、标记日期、标签和短评。标记日期不必然等于真实播放日期，不代表已知播放进度或观看时长。

**收藏与收藏夹**：收藏为个人星标；收藏夹为用户命名的作品清单，一部作品可以属于多个收藏夹。媒体来源目录不称为收藏夹。

**智能文件夹**：将明确对应单部电影、某部剧或某季的媒体目录以影视卡片展示的浏览方式。它不改变实际文件位置或目录结构。
